# Reproduction guide

## Scope

The core pipeline downloads the two Rfam 15.1 seed alignments, validates Stockholm alignment and consensus-structure lengths, classifies paired/unpaired/reference-insertion columns, and regenerates the descriptive QC, per-column, pair-composition and summary tables. It does not reproduce every structural-annotation panel or the deposited-structure rendering workflow.

## Environment

Python 3.10 or newer is recommended. Install the pinned-minimum dependencies listed in `requirements.txt`:

```bash
python -m venv .venv
# activate the environment for your operating system
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

## Run the core analysis

From the repository root:

```bash
python -m src.download_rfam
python -m src.run_analysis
pytest -q
```

The downloader retrieves the Rfam seed alignments. The analysis writes generated tables and figures under `results/`; raw alignments are expected under `data/raw/`. The public repository intentionally does not commit duplicate raw seed files. Check the Rfam source and checksums in [data provenance](data/README.md).

## Public result tables

The curated summaries used in the report are committed under `data/tables/`. The restricted mitochondrial tRNA-Phe(GAA) locus metrics are under `supplementary/tables/`. The corresponding main and supplementary figures are SVG files under `manuscript/figures/` and `supplementary/figures/`.

## Figure-generation boundaries

The scripts under `scripts/` cover the conservation/entropy visualization and selected RNA biology context panels. Some panels depend on additional structural-analysis outputs (including R-scape, FR3D, and ViennaRNA) and source tables that are not all generated by the core two-family pipeline. The 9ZTL structural context was generated from a deposited PDB/mmCIF structure and is linked to the RCSB entry in the report; it is not presented here as an independently reproducible image pipeline. No claim is made that every SVG can be rebuilt from only `requirements.txt`.

## Interpretation safeguards

All paired-versus-unpaired summaries are descriptive. Alignment columns are not independent evolutionary replicates. The public results do not establish compensatory evolution, causation, or a universal family-level rule. The TN93 inferential workflow is excluded because its convergence acceptance gate was not met.
